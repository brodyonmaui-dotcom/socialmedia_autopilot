## Instagram (route: Graph API, Facebook Login, Page token, graph.facebook.com, v25.0)
- Login: Instagram Login (graph.instagram.com, no Page) vs Facebook Login (Page, resumable upload); one per app. **Business Discovery and Hashtag Search are Facebook Login only** (Hashtag Search also needs App Review) -> Facebook Login (decision 6).
- Publish: create container (`media_type=REELS`, public `video_url`) -> poll `status_code` until `FINISHED` (~1/min, up to 5 min) -> `media_publish`. **Containers expire after 24 h**; no schedule parameter exists, so the server fires each post at fire time (never pre-create). 400 containers per rolling day.
- Publish cap: docs say 100 or 50 per rolling 24 h; **account quota reads 0/100** (probe 2026-11-10).
- Reels: 3 s-15 min, <=300 MB, 23-60 fps; `cover_url` (9:16 JPEG), `share_to_feed`, `collaborators` <=3, caption 2,200 chars. Hashtags: docs say 30, IG reportedly enforces 3-5 (since Dec 2025) -> **<=5**.
- Audio: `audio_name` renames original audio only; music library can't be attached; a trending song baked into the file posts as original audio. Licensed-music reels come back **without `media_url`** (own and others') -> keep own masters.
- Trial reels (Dec 3 2025): `trial_params.graduation_strategy` = `MANUAL` (graduate in native app) or `SS_PERFORMANCE` (auto). **No endpoint to graduate or read trial status.** Default MANUAL. One vendor reports ~20 trials/day API limit (unverified; irrelevant).
  - Eligibility decided at publish time. Our account was refused 2026-11-10/11 (x2) and 2026-11-12 with `code 10 / error_subcode 2207081` "Application does not have permission for this action" at ~137 followers (no threshold named; 2207081 not in the error-codes reference). Claim (creator via Meta AI 2026-11-11, third-party guides agree; no official page found): public professional account with **200+ followers** (personal 1,000; older reports 1,000 for all). IG User Media reference documents no eligibility rule. Fallback (plain reel + flag) fires on code 10 / subcode 2207081; log them. Re-probe daily, at 200 followers, and after permission/data-access review. Trial insights availability unknown.
- Reel insights (v25, probe 2026-11-10/14): accepted `views, reach, saved, shares, ig_reels_avg_watch_time, ig_reels_video_view_total_time, reels_skip_rate, reposts`; **rejected `follows, profile_visits`**. Metric is `saved` not `saves`; one wrong metric fails the whole request. Lag up to 48 h; no insights webhooks under Instagram Login; some account metrics withheld under 100 followers.
- Comments: **polling first** (one `/media?fields=...,comments{...}` call every 3-5 min is cheap). Webhooks: app must be Live; Meta's webhook docs say `comments`/`live_comments` need Advanced Access (App Review + Business Verification); not proven for Standard Access (open). Development mode = no real webhooks.
- Comment API (docs 2026-11-12): list `GET /{ig-media-id}/comments` = top-level only, newest first, max 50/query; replies via `replies{...}`. Fields `id, text, timestamp, parent_id, hidden, like_count, media{id}, from{id (IGSID), username}, username`. `user` only on the account's own comments -> `from.id` = `IG_USER_ID` marks ours. Age-gated media/restricted users not returned. Reply `POST /{ig-comment-id}/replies?message=` -> `{id}`, top-level only; no idempotency key -> existence check = `GET /{ig-comment-id}/replies?fields=id,text,from`. Hide `POST /{ig-comment-id}?hide=true` -> `{success:true}` (owner's own comments can't be hidden). Delete exists; never used. Private replies 750/h. Probe 2026-11-14: `from.id`, `username`, `hidden` present on all 10 top-level comments and 12 replies in Development mode; per-person limits key on `from.id`.
- DMs: reply only within **24 h of the user's last message**; app can't open conversations; 7-day Human Agent window is a separately reviewed feature -> past 24 h the draft becomes "copy + open Instagram". API-received messages stay unread in the IG app. Conversations API (`/conversations?platform=instagram`, or `/me/conversations` with Page token; `/{conversation-id}?fields=messages`): 20 most recent messages per thread; Requests-folder threads inactive 30 days not returned; may need IG setting Message controls -> Connected tools -> Allow access to messages. **DM read works** (probe 2026-11-14). `dm-poll` off by default.
- App Review: "Not required" for an app serving only a business you own (otherwise 2-4 weeks per permission). App "Development" mode, Standard Access, user is only role. Page linked to the IG Business account.
- Business Discovery works at Standard Access in Development mode (probe 2026-11-10); shape under "Business Discovery response shape".
- Tokens: Page token **never expires**; **data access until 2027-02-08** (90-day window): re-run `probe:connect-meta` before then; worker alerts 7 days ahead. `connect-meta` granted all 8 scopes (content_publish, manage_comments, manage_messages, basic, manage_insights, pages_read_engagement, ...). Old USER token (expires 2026-12-18, read-only) replaced; allowed to lapse.
- Reachability (cloud session): graph.*, googleapis.com, zernio.com, api.anthropic.com answer; developers.facebook.com and docs.zernio.com don't resolve for WebFetch (use `curl <page>.md|.mdx`); SSH blocked.

## YouTube (route: Data API v3 + Analytics API, unverified app "In production")
- Quota: since 2025-12-04 upload ~100 units (was ~1,600); since **2026-06-01** `videos.insert` and `search.list` each have their own bucket of **100 calls/day at 1 unit**; `videos.batchGetStats` (June 2026) for cheap public stats. Pool 10,000 units/day; list = 1 unit; `comments.insert` and moderation 50 units (~190 replies/day). English Google pages were unreachable at first (facts from the .cn mirror; Nov 2 change re-confirmed on developers.google.com).
- **2026-11-02: uploads from unverified projects are no longer locked private** (confirmed, default privacy public unless set). 2026-11-03: `thumbnails.set` supports custom Shorts thumbnails.
- Scheduling: upload private + `status.publishAt` (error `invalidPublishAt`); YouTube holds the clock. Live check (2026-11-10): works, videos flipped public on schedule. No `isShort` flag; Shorts classified from the file. Shorts >60 s with a music copyright claim get blocked -> keep <=60 s when licensed music is used (old project trimmed to 58.5 s).
- OAuth: project in "Testing" = **7-day refresh tokens**; unverified "In production" = warning screen, 100-user cap, fine for one user. App has **no logo** (a logo triggers brand verification); branding needs homepage/privacy/terms URLs + authorized domain served from the VPS. Desktop OAuth client via paste-the-redirect-URL flow; refresh token in `.secrets/yt.json` on the VPS. Console shows the client secret only once (use "Add secret" if unsure). Token refresh costs no Data API quota. Granted scopes (probe 2026-11-14): `yt-analytics.readonly`, `youtube.upload`, `youtube.force-ssl`.
- Comments: `commentThreads.list?allThreadsRelatedToChannelId=` 1 unit; `comments.insert` (`snippet.parentId`) and `comments.setModerationStatus` (`heldForReview|published|rejected`, `banAuthor` only with `rejected`) 50 units each, need `force-ssl`. Replies stay shadow behind `YT_COMMENT_REPLIES` + engagement mode. Open: `yt.comment_threads` returned 0 threads, so `authorChannelId` unconfirmed.
- Stats: `videos.list?part=statistics` -> `viewCount, likeCount, commentCount` **strings**; `dislikeCount` owner-only; `favoriteCount` 0. Watch time only via Analytics API (`averageViewDuration` s, `estimatedMinutesWatched`, `averageViewPercentage`, `engagedViews`, `subscribersGained`, `shares`; `yt-analytics.readonly`). `channels?part=statistics` strings, `hiddenSubscriberCount` true -> followers null. `videos?part=snippet,statistics,contentDetails` -> title, description, ISO 8601 `duration`.
- `findExisting` via uploads playlist (discovery doc rev 20261112; reference pages not re-read): `channels.list mine=true` -> `contentDetails.relatedPlaylists.uploads` -> `playlistItems.list`. `snippet.publishedAt` = upload time (~24 h before `publishAt`); `contentDetails.videoPublishedAt` = go-public time; items carry **no `publishAt`**; `privacyStatus` public|unlisted|private. Cost 2 units first lookup, 1 after caching (not re-verified). **Unverified:** whether private/scheduled uploads appear there and how fast; newest-first order (first page of 25 read). A miss is not proof of absence. Code matches normalised title + `publishedAt` in [scheduledFor-14 d, +36 h]; on retry `null` = publish again (only before the upload PUT), stale publishing + `null` = `unknown` + alert, throw = requeue, never resent. Re-check with one private scheduled test upload (creator's OK).

## TikTok (route: Zernio, Business-API lane)
- Direct API: Direct Post (`video.publish`), Upload-to-Inbox (`video.upload`). Unaudited apps: private accounts only, `SELF_ONLY`, <=5 users/day, error `unaudited_client_can_only_post_to_private_accounts`, silently private. The audit rejects personal/utility tools, so self-built posting is no fallback (sandbox: 10 owned accounts, no public posting). No sound or scheduled-time parameter; ~15 posts/day per creator; init 6/min/token; `PULL_FROM_URL` needs a verified domain. Inbox drafts must be finished within 24 h (Postiz).
- Zernio pricing (docs read 2026-11-09/11): **$0 boundary = 2 connected accounts** ("$12 monthly credit"); posts unlimited; 3rd account returns `402 PAYMENT_REQUIRED` (`free_tier_exceeded`) without a card, else **$6/account/mo (3-10)**, then $3/$1 bands; Page + its IG + Meta ad account count as 3. Free tier 60 req/min. Inbox: 10,000 outbound DMs/mo included ($1 per 10k; comment replies/received don't meter; no card -> `403 message_allowance_exceeded`). Other meters (X API, Automations >2,000 runs, SMS, ads) not needed.
- Lane: since 2026-09-10 new connections use TikTok's **Business app**: direct posts **public only**; non-public = Creator Inbox drafts (`tiktokSettings.draft: true`, TikTok app >= 31.8, **max 5 pending/24 h**, a 6th fails until drafts are finished; drafts count toward daily caps; Zernio marks a draft `published` when TikTok accepts it). Connected with no Business-account prompt (probe 2026-11-10, 3/3 passed); personal accounts work; whether the lane forces a Business account (Commercial Music Library only) is open. DMs need a Business Account, comment management doesn't. Comments arrive by **webhook**.
- Caps (rolling 24 h per account): Zernio 15 videos + 15 photo posts and 25 posts/hour; over-cap posts are **held and published later, not failed**. TikTok's own per-account API limit (number undocumented) fails with "You have created too many posts in the last 24 hours via the API" and isn't retried. Captions 2,200 chars; video 3 s-10 min, <=4 GB.
- Safety features: `Idempotency-Key` header (24 h window; retry returns the original post), `scheduledFor` + `timezone` (Zernio holds the clock), `dryRun: true` on create-post (TikTok only, creates nothing). A `publishNow` rejection returns `207` with `post.status: "failed"`.
- Errors: "Duplicate content detected" (change caption/media); `spam_risk` (API moderation stricter than app); large-upload timeout = "unknown", check later; `403 PLATFORM_BETA_RESTRICTED` (Snapchat). Live 2026-11-10/12: `201 status=published` at once; **`platformPostUrl` empty right after posting** -> verify on the TikTok profile. No find-post-by-key endpoint.
- Music: only Commercial Music Library tracks (Business lane). Not possible via API: sound search, duets/stitches, effects, editing after publish, starting DMs, For You analytics.
- Analytics: `GET /v1/analytics?postId=` -> `analytics` (impressions, reach, likes, comments, shares, saves, clicks, views, follows, `igReelsAvgWatchTime` ms) + `platformAnalytics[]` (`syncStatus`). TikTok: likes, comments, shares, views. `202` = syncing; **`402` = "Analytics add-on required"** on legacy plans (plan type unconfirmed). Summary: `docs/tiktok-free-plan.md`.
- Fallbacks if Zernio fails: Upload-Post ($16/mo yearly, $24 monthly; free tier 403s TikTok; 15 TikTok posts/day) or native posting. Others: bundle.social (audited TikTok; free 20 posts/mo, Pro $90-100), Ayrshare $149 (Snapchat allowlisted).

## Snapchat (route: assisted, Web Share API)
- Public Profile API (<=1 GB chunked uploads, Stories, Spotlight `SUBMITTED|LIVE|REJECTED`) is **allowlist only** (no published criteria). Snap Terms (eff. 2026-09-21) forbid automated access without written consent -> no browser automation. No public Snapchat comments API.
- Zernio: **Snapchat unavailable** ("Snap has not approved Zernio's app ... `403 PLATFORM_BETA_RESTRICTED` ... no release date"); marketing pages contradict this, docs win.
- Creative Kit: Spotlight sharing is iOS-native-SDK only (web needs Snapchat 10.67+), so a PWA can't use it. Working path: **Web Share API -> iOS share sheet -> Snapchat** (iPhone test 2026-11-10: 1-minute video arrived full length, caption carried, Story and **Spotlight** offered). Gotcha: **blank sheet** until Snapchat was opened recently; UI says "if blank, open Snapchat once, then retry." Spotlight 5-60 s, 9:16; 1/day.
- Still to check in M2: location / Snap Map off on the posting screen. The creator will create a new dedicated Snapchat account for the brand.
