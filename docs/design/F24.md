# F24: Studio, an Edits-style editor inside the app

Status: spec, 2026-11-26. Modelled on Instagram Edits' core (research 2026-11-26: trim, split/reorder, text styles, sound under the original, direct publish). **No migration**: a render is a `media_edits` row with `kind = 'studio'` and the edit decision list (EDL) in `params`; `source_media_id` = first clip. The output lands in the Library and in **Ready to post** (the creator watches the result, then Approve & schedule). Nothing auto-approves.

## EDL (exact; S1 owns `packages/media/src/edl.ts`, S2 builds it in the browser)
```ts
export interface Edl {
  v: 1;
  fit: "fill" | "fit";                       // 1080x1920: fill = crop to cover, fit = blurred pad (reuse fix.ts pad)
  clips: { mediaId: string; inS: number; outS: number; speed: 0.5 | 0.75 | 1 | 1.25 | 1.5 | 2 }[]; // 1..10 clips, in order
  texts: { text: string; startS: number; endS: number; position: "top" | "center" | "bottom"; style: "bold" | "plain" }[]; // 0..10, times on the output timeline, text ≤ 80 chars
  sound: { soundId: string; offsetS: number; volume: number } | null;  // volume 0..1.5, starts at output 0, sound read from offsetS
  originalVolume: number;                    // 0..1.5 (voiceovers: default 1)
  coverS: number | null;                     // poster frame on the output timeline
}
export function parseEdl(raw: unknown): { ok: true; edl: Edl } | { ok: false; error: string };
export function outputDuration(edl: Edl): number;                 // Σ (outS − inS) / speed; must be 3..90 s
export function edlArgs(edl: Edl, inputs: { clipPaths: string[]; soundPath?: string; fontPath: string; outPath: string }): string[]; // pure
export async function runEdl(...): Promise<{ outPath: string; durationS: number }>;
```
Rendering: per clip `trim`/`atrim` + `setpts=PTS/speed` + `atempo` (chain for 0.5), scale/crop or pad to 1080×1920, 30 fps, `concat`; clips without audio get silence; `drawtext` per text (fontfile from the worker image, white text with a soft shadow/box, safe margins: top 12%, bottom 22% to clear IG UI, `enable='between(t,start,end)'`, text escaped for ffmpeg); audio = original × originalVolume `amix` sound × volume (sound trimmed/looped to length, 0.3 s fade-in, 1 s fade-out), two-pass loudnorm −14 LUFS; metadata stripped (fix.ts `META`) and location re-checked; poster from `coverS`. Text overlays must pass the privacy lint (`PRIVACY_BLOCKLIST`, the caption lint's location rule) before queueing.

## Interfaces S1 builds (web), S2 consumes

Worker: `apps/worker/src/jobs/media-reel.ts` handles `kind = 'studio'` via `runEdl` (download all clips + sound; one render at a time); result media `derived_from` = first clip, folder "Studio"; **no** batch item (it appears in Ready to post). Worker image: make sure a TTF font is installed (apps/worker/Dockerfile: add `font-dejavu` / `fonts-dejavu-core` for the base image's package manager) and expose its path via a constant.

### S2 editor (phone + laptop)
Clip picker (library clips by folder, search) → **timeline**: ordered clip strips with thumbnail, in/out handles (two range inputs + numeric seconds), **Split at playhead**, speed menu, move left/right (and drag on desktop), delete. **Preview**: a `<video>` that plays the clips in order honouring in/out/speed (client approximation; say "Preview is approximate, the export is exact"), text overlays drawn as positioned CSS over the video while their time window is active, the sound playing in an `<audio>` element at its volume, total duration counter (3–90 s limit, red when outside). **Text**: add/edit/delete overlays with start/end (default = current playhead + 3 s), position, style. **Sound**: pick from Sounds (link to upload more), offset, volume; original volume slider (default 100% for voiceovers). Fit / Fill toggle. **Cover**: "Use current frame". Project autosaves to `localStorage` (try/catch). **Export** → confirm with duration and summary → `queueStudioRenderAction` → status chip (poll `/app/studio/status`) → when done: "Ready to post" link. 12-hour times only where clock times show.
