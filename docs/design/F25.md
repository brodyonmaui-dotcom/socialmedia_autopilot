# F25: Studio text you can drag, size and style

Status: spec, 2026-11-26. Creator feedback on F24: "position + style" is clunky; wants more control and to drag text around inside the clip. No migration (the EDL lives in `media_edits.params`).

## EDL text v2 (backward compatible; `packages/media/src/edl.ts` owns it, still import-free)
```ts
export const TEXT_COLORS = ["#FFFFFF", "#000000", "#FFD60A", "#FF3B30", "#34C759", "#0A84FF", "#FF2D92", "#BF5AF2"] as const;
export interface EdlText {
  text: string; startS: number; endS: number;
  position: "top" | "center" | "bottom";        // kept: old EDLs + the quick presets; x/y win when present
  style: "bold" | "plain";                       // font weight (bold = DejaVuSans-Bold)
  x?: number; y?: number;                        // 0..1 anchor in the 1080x1920 frame (y = block centre; x per align)
  size?: number;                                 // font px as a fraction of the width, 0.03..0.16
  color?: string;                                // one of TEXT_COLORS
  bg?: "none" | "shadow" | "outline" | "box";    // look
  bgColor?: string;                              // box colour, one of TEXT_COLORS (drawn at 60% opacity)
  align?: "left" | "center" | "right";
}
/** Resolved layout, shared by the renderer AND the browser preview so they match exactly. */
export interface TextLayout { lines: string[]; px: number; lineH: number; x: number; y: number; align: "left"|"center"|"right"; color: string; bg: "none"|"shadow"|"outline"|"box"; bgColor: string; bold: boolean }
export function textLayout(t: EdlText): TextLayout;
```
Defaults when absent (old EDLs render as before as closely as possible): `align` center, `x` 0.5, `color` #FFFFFF, `bg` = style bold → "box", plain → "shadow", `bgColor` #000000, `size` = bold 0.07 / plain 0.06; `y` from position: top → 0.12 + half block height (in frame fraction), center → 0.5, bottom → 0.78 − half block height.
Layout: `px = round(size*1080)`; wrap at `maxChars = max(4, floor(0.9*1080 / (px*0.55)))` using `wrapText`; if the longest line still exceeds 0.92 width at `px*0.6` per char, shrink px to fit; `lineH = round(px*1.3)`; `y` clamped so the block stays inside the frame; `x` clamped 0..1.
parseEdl validates the new fields (numbers in range, colour in TEXT_COLORS, enums) with plain-language errors; unknown/absent = defaults.
drawtext per line: top = `y*1920 − blockH/2 + k*lineH`; x: center `X−text_w/2`, left `X`, right `X−text_w` where `X = round(x*1080)`, clamped inside the frame (`max(0, min(w−text_w, …))`); `fontcolor=<hex>`; shadow `shadowcolor=black@0.6:shadowx=3:shadowy=3`; outline `borderw=max(2,round(px*0.07)):bordercolor=black` (white outline when text colour is #000000); box `box=1:boxcolor=<bgColor>@0.6:boxborderw=round(px*0.22)`.

## Editor (apps/web: `lib/studio/editor-state.ts`, `components/studio/*`)
- **Drag on the preview**: each active text is a positioned element using `textLayout` (font-size = `px/1080*100` cqw on a container-query frame, line-height `lineH/px`, lines joined with line breaks, left = x*100%, top = y*100%, translate −50%/0/−100% by align and −50% vertically). Pointer events with pointer capture move it (updates x/y, clamped); tap selects; selected text has a ring and a **corner handle** that resizes (size). While dragging: dashed IG safe-zone guides (top 12%, bottom 22%) and a centre line; snap to x = 0.5 and to y = 0.5 within 2%. Video controls must not steal the drag (overlay layer above the video; tap empty area = play/pause as now).
- **Text panel** (selected text expanded, others collapsed to a one-line chip): multiline text (≤ 80 chars), **Bold/Plain** chips, **Look** chips None / Shadow / Outline / Box, **colour swatches** (TEXT_COLORS), box colour swatches when Box, **size slider**, **align** segmented L/C/R, quick place buttons Top / Middle / Bottom (sets y via the old preset formula), "Centre", timing with **Start at playhead / End at playhead** buttons plus numeric fields, Duplicate, Remove. Adding text selects it and puts it at the centre.
- The project autosave (localStorage) keeps working with old saved projects (missing fields = defaults).
