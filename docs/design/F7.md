# F7: red-team checklist for the final review

> **Read `docs/prep/run-2-decisions.md` first.** It answers every open question below and corrects this draft (it wins on conflict).

Status: design (prep run 2, 2026-11-12). Baseline green, so **no task 0**. Scope: repo-wide, **fixes + tests only, no features** (fable-week.json). Line numbers are for `main` @ `290d430`. F2/F3 will shift them, so re-grep before citing.

## Goals
Find and fix, with a regression test each:
- every way a post or reply can go out twice, or go out unapproved;
- every way a secret or a location can leak (logs, alerts, DB rows shown in the UI, committed files, generated text, media metadata);
- every auth gap.

## Non-goals
- New features, refactors for taste, dependency upgrades (unless a CVE applies), live calls.

## How to run it
- One subagent per section (A–E), each told to **write a failing test first, then the fix**. Sections are parallel-safe except where they share a file (noted per section).
- Each finding goes into a table in the PR: `id · severity (high/med/low) · file:line · test · fixed?`.
- Anything needing a platform fact goes to "needs creator / platform-check", never a guess.

## Interfaces / data model
- None new. New tests only, except for the fixes listed below.
- A migration is only needed if a constraint fix is chosen (A6, with the next free number, likely `0008_constraints.sql`).
